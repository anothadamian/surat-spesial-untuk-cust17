# Untuk Felicia

Website permintaan maaf personal dari Tornagogo untuk Felicia, disesuaikan dengan data customer di `data.txt`.

## Menjalankan website

```bash
npm ci
npm run dev
```

Buka `http://localhost:3000`. Untuk membuat versi produksi statis, jalankan `npm run build`; hasilnya berada di folder `out/`.

Isi surat utama dibaca dari `letter.txt`. Foto customer berada di `public/photos/felicia-memory.jpeg`, sedangkan lagu Panasea berada di `public/music/panasea.mp3`. Musik mulai dicoba setelah surat dibuka dan tetap memiliki tombol Play/Pause apabila browser menolak pemutaran otomatis.
